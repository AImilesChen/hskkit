# HSK4 complete mock papers

Scope: publish user-accepted A/B/C at `/hsk-test-prep/hsk-4/mock`. A is free; B/C reuse the current Pro subscription/trial/pass entitlement. Existing HSK1–3 papers, prices, payments, database schema and schedules are unchanged.

Each paper has 70 tasks and no unscored examples: 32 listening, 32 reading, five picture sentences and an 80-character-minimum short passage. Allow five minutes to prepare, followed by a server-timed 80-minute attempt: listening 20, answer transfer 5, reading 30, writing 25. Dialogues and shared listening passages are read once. Reading passages are displayed once per question group, retaining numbered blanks. The sound check previews question 1 and is labelled accordingly.

Choice answers save immediately; sentence and passage drafts save explicitly and can be restored. A draft below 80 Chinese characters can be saved; the counter excludes punctuation, digits and Latin letters. A failed save exposes retry; expiry submits saved answers. Listening and reading each report raw marks out of 32. All six writing tasks remain ungraded with reference responses and separate editorial rubrics; writing is never combined into an official score or pass prediction.

Server-only runtime data and all deployed media are hash-bound to the three accepted content snapshots. Student projections omit scored answers, scripts, explanations and writing references. The existing protected ASSETS delivery checks B/C entitlement before access, including range requests; middleware continues to deny direct static asset paths. No production migration or new scheduled job is required.

Release verification, source SHA, Worker version, actual production checks and rollback evidence are recorded separately after deployment. This note does not claim production verification in advance. Existing cache cleanup remains disabled. Local fixtures and local clock changes are excluded from publication.
