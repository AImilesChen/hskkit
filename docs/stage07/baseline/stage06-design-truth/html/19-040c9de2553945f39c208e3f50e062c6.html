The 'ba' Construction

Used to emphasize the result of an action on a specific object.

info Core Concept

The 把 (bǎ) construction is a unique Chinese grammar pattern. Instead of the typical Subject-Verb-Object (SVO) order, it uses Subject + 把 + Object + Verb + Result. It signifies that an action has been done to an object, resulting in a change of state, position, or condition.

Structure

1. Subject 我 (Wǒ)
2. Ba + Object 把书 (bǎ shū)
3. Verb 放 (fàng)
4. Result 在桌子上 (zài...)

Formula: Subject + 把 + Object + Verb + Other Element (Complement/Le/etc.)

Key Examples

我把作业写完了。

Wǒ bǎ zuòyè xiě wán le.

I finished writing the homework.

请把门关上。

Qǐng bǎ mén guān shàng.

Please close the door.

他把咖啡喝了。

Tā bǎ kāfēi hē le.

He drank the coffee.

Important Rules

  • check_circle
    Definite Object The object following 把 must be specific or known to both speakers (e.g., "the book", not "a book").
  • check_circle
    Verb Complexity The verb cannot stand alone. It must be followed by a complement, 了 (le), or a reduplicated verb to show the result.
  • cancel
    Verbs of State/Emotion Do not use 把 with verbs like 喜欢 (like), 知道 (know), or 是 (to be).
