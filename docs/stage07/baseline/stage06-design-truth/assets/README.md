# Assets contract

No standalone logo, illustration, or marketing-image files were exposed by the final official Stitch Screen exports. Visual assets currently used by the designs are embedded/referenced in the official HTML and captured in the official screenshots.

Production implementation rules:
- replace remote font/icon CDN dependencies with approved self-hosted or bundled equivalents;
- do not treat placeholder learning-object previews as production content;
- do not infer additional product capabilities from decorative assets.
