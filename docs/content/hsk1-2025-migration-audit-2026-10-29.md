# 新版 HSK 1 词汇迁移核验（内部工作稿）

日期：2026-10-29。对照依据：[汉考国际公开的新版 HSK 考试大纲](https://www.chinesetest.cn/HSK)所链接的 PDF，SHA-256 `ec74ce0439e837bbb15154be13e747ae798903b2fd3a331629df6c3b45504941`。旧数据依据：生产提交 `73d61b98269f706f2b6e8c0b95a7c7c630a81720` 的 `public-catalog-index.json`。本文件只记录数量及迁移问题，不转载官方整份词表。

## 逐词对照结果

官方新版 HSK 1 是 **300** 个词条（PDF 物理第 80–87 页），站点当前 HSK 1 是 **500** 个词条。`scripts/content/audit-hsk1-2025.py` 逐条核对序号 1–300、词形及带调拼音，并生成以下分类：

| 分类 | 新版词条数 | 处理 |
| --- | ---: | --- |
| 当前 HSK 1 词形和拼音都对应 | 256 | 复用已授权的释义作为编辑底稿；仍须核对词义和词性 |
| 当前其他等级词形和拼音都对应，且唯一 | 27 | 在新版 HSK 1 中建立新等级归属；保留旧学习 ID 映射 |
| 同词形但读音或义项不同，人工已确定旧 ID | 6 | 包含 5 处变调或轻声、1 处同音异义；新释义和音频仍需编辑 |
| 当前词库没有同词形词条 | 11 | 从有许可的词典数据及自编教学内容新增 |
| **合计** | **300** |  |

另外，旧 HSK 1 有 **239** 条按词形无法对应新版 HSK 1。它们不可直接删除：历史学习记录、旧词条链接和可能仍适用于其他等级的词义都需要保留。另有同一汉字的不同读音、义项，不能仅凭汉字合并记录。官方 PDF 有 6 行未解析出词性，需查看页面原文手工校对。

## 发布前的内容校验

1. 6 个同形疑点已核对并选定旧 ID，剩余 11 个是旧库没有的新词。先完成这些词的新释义和拼音编辑；重点检查不、一的变调、轻声，以及同形异义的词。旧词库中的“不客气”“一点儿”“喂”等释义混入了其他用法，不能机械复制成“新版官方释义”；官方大纲并未提供英文释义。
2. 对 256 条自动匹配和 27 条跨等级词逐条抽查实际义项，核对简繁体、词性、拼音、已有音频与词条显示。新词须采用站点已许可的 CC-CEDICT 数据或自编内容，并保留每条来源；不能把官方音频或试题直接搬入站点。
3. 为新版本单独生成稳定词条 ID、旧 ID 对照表和内容版本。学习、复习、Today、错题、收藏中仍指向旧 ID 的记录保留且可读，不以新词覆盖旧记录。
4. 在开发环境核验 HSK 1 列表、搜索、详情、闪卡、练习、Today、Review、sitemap 和资料包文案；新 HSK 1 标注 300 词，其他等级在迁移前仍需准确标明旧数据依据。
5. 发布前刷新 D1 的恢复时间锚点并记录聚合计数；上线后以相同口径比较 Worker CPU、错误率与 D1 读写，避免按一次页面加载推断整站成本。

详细逐词对照保存在本机临时目录，**不提交到公开仓库**。核验脚本只打印汇总数量；只有传入 `--private-crosswalk` 才在指定的本地路径生成细表。`scripts/content/build-hsk1-2025-draft.py` 已用细表生成 300 条本地编辑草稿，其中 289 条保留旧 ID 对照、11 条有独立编写的简短英文释义。已逐条进行第一轮释义审读，对旧词库中多义、错义或不适合初学者的 **144 条**释义做了简化；例如“本”要显示书本量词义，“穿”要显示穿衣义。官方未给出词性的 6 个固定短语在草稿中使用自编的 `Phrase` 标签，并分别保存官方原始词性字段；不能误称这是官方给的词性。词性已映射为站点现有的 `N/V/Adj/Adv/...` 过滤值。草稿明确标记为 `draft-not-for-publication`，每条释义和音频仍标记待上线验收；脚本禁止把完整草稿写进公开 Git 工作区。两个脚本都不修改生产数据库或线上词条。

### 音频差距

在 300 条草稿中，289 条有旧词 ID；其中 269 条的旧 ID 已有关联的已批准词语音频，20 条没有。11 条全新词没有旧音频。另有 4 条虽然有旧音频，但官方拼音涉及变调或轻声，不能未经试听直接复用。因此当前**最多 265 条音频可作为复用候选，至少 35 条需要制作或重新核验**。这不是已完成音频验收的数量。

## 本次上线候选的实际范围

编辑后的 300 条 HSK 1 词条已生成独立的 `hsk3-hsk1-2025-v6` 发布版本，公开等级列表、词条详情、搜索、闪卡和 Today 使用新版 ID。265 条复用既有发音，35 条新生成发音；逐文件校验覆盖率、格式、时长和校验和，详见 `docs/quality/hsk1-2025-audio-report.json`。这些自动检查不能代替真人逐条试听，站长将在上线后抽听。
