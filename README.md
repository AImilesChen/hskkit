# HSKKit

HSKKit is an AI-powered Chinese learning toolkit for HSK learners.

## Product scope

P1 focuses on practical study tools:

- AI worksheet generation
- AI graded reading generation
- Flashcards for HSK vocabulary
- Free daily limits with Pro subscription
- PayPal USD payments

## Stack

- Next.js App Router
- TypeScript
- CSS modules/global CSS
- Planned deployment: Cloudflare Workers / OpenNext or Vercel depending on final deployment choice

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
