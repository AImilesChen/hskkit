# HSKKit SEO 矩阵页模板 Prompt

## 复用规则

每个 SEO 工具页遵循以下结构，配色、字体、导航、Footer 完全复用首页。

## Color Scheme (复用首页)
- Background: #0D0D12
- Surface: #16161D
- Primary accent: #E63946
- CTA / highlight: #F4A261
- Text primary: #F5F5F0
- Text secondary: #8A8A93
- Border / divider: #2A2A35

## Typography (复用首页)
- Display: Space Grotesk
- Body: DM Sans
- Chinese fallback: Noto Sans SC

---

## 页面结构

1. NAVIGATION (完全复用首页)
- Fixed top nav, Logo + links + CTA

2. HERO SECTION
- Layout: Split layout or centered (depending on tool complexity)
- Headline: [针对关键词的标题] — e.g., "Free HSK Level Test — Know Your Chinese Level in 2 Minutes"
- Subheadline: [针对搜索意图的描述]
- Primary CTA: [工具主行动] — e.g., "Start the Level Test"
- Secondary CTA: [次行动] — e.g., "Learn More About HSK Levels"
- Hero visual: [工具截图 / 工具嵌入式 demo]

3. TOOL DEMO
- Embedded tool or screenshot
- Interactive element if applicable
- Clear instructions

4. HOW IT WORKS (针对该工具的 3 步骤)
- Step 1: [具体步骤]
- Step 2: [具体步骤]
- Step 3: [具体步骤]

5. BENEFITS (2-3 个核心优势)
- Benefit 1: [标题 + 描述]
- Benefit 2: [标题 + 描述]
- Benefit 3: [标题 + 描述]

6. RELATED TOOLS
- Links to other tool pages
- Card grid, 2-3 items

7. FAQ (3-5 个针对该工具的问题)
- Q1: [问题]
- A1: [答案]
- ...

8. FINAL CTA (复用首页)
- Headline: "Ready to Start Your Daily HSK Practice?"
- Primary CTA: "Start Today's HSK Practice — Free"
- Secondary CTA: "Take the Free HSK Level Test"

9. FOOTER (完全复用首页)
